# 免责与合规声明

## 1. 项目性质

本仓库是对某 Android 教育类应用的**逆向工程研究笔记**，用于学习以下技术：

- Native 层请求签名算法与完整性校验
- 对称加解密的 CPU 模拟与自动化 patch
- Android DEX 注入与改包
- WebView JSBridge 劫持与前端自动化

内容为**说明性关键片段**，不是可直接编译运行的完整工程。

## 2. 本仓库不含

为尊重第三方权益并保护隐私，本仓库**刻意不包含**：

- 目标应用的**原始** APK 与完整反编译源码（仓库内的成品 APK 为官方 v52 的重打包产物，见下方说明；反编译源码以独立 zip 分发，不入库）
- 任何真实登录凭据（Cookie / token / deviceId / 用户标识）
- 任何个人账号信息、设备信息、会话信息
- 任何与研究过程相关的私人对话或通信记录
- 签名密钥库

**关于自带的成品 APK**（仓库根 `release/` 目录）：这是基于目标应用官方 v52 版本**重打包**
的研究产物——内含官方 APK 的 dex、资源与 Native 库（相关版权归原厂所有），外加本项目的
注入代码。它仅用于复现验证所述技术机制，受第 3 节使用限制约束，**请勿用于线上对局**。

文中出现的路径、常量、偏移量仅用于说明技术原理，均已做泛化处理。

## 3. 使用限制

**禁止**将本项目用于：
